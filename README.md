# سكربت توليد مرصد غياب الطلاب من Excel

هذا الملف يعيد إنشاء **مرصد غياب الطلاب** من كشف Excel بنفس أعمدة ملف المصدر، مع الاحتفاظ بالتحليلات والتقويم والتصفية والطباعة الموحدة.

## المكونات

- `إنشاء_مرصد_الغياب.py`: سكربت Python مستقل، دون مكتبات إضافية.
- `قالب_مرصد_غياب_الطلاب.html`: قالب اللوحة **خالي من بيانات الطلاب**.

## الاستخدام على Windows

1. ثبت Python 3.9 أو أحدث إن لم يكن مثبتًا.
2. ضع ملف Excel الجديد في المجلد نفسه الذي يحتوي على الملفين أعلاه.
3. افتح PowerShell في ذلك المجلد ونفّذ:

```powershell
python .\إنشاء_مرصد_الغياب.py ".\غياب_جديد.xlsx"
```

لتحديد الفترة الافتراضية المراد عرضها (يمكن تغييرها من داخل اللوحة لاحقًا):

```powershell
python .\إنشاء_مرصد_الغياب.py ".\غياب_جديد.xlsx" --start 2026-09-27 --end 2026-11-09
```

سينتج ملف HTML مستقل بجانب ملف Excel. افتحه في Chrome أو Edge.

## البنية المطلوبة لملفات Excel

| العمود | المحتوى |
|---|---|
| C | تاريخ الغياب بصيغة يوم-شهر-سنة |
| G | الفصل: مثال `أول 1`، `ثاني 2`، `ثالث 3` |
| L | اسم الطالب |
| O | الرقم التعريفي للطالب |
| H2 | اسم المدرسة (اختياري) |

يبدأ الجدول من الصف 12؛ ويتجاهل السكربت أسطر «إجمالي الغياب». ويرصد السجلات المكررة أو غير المكتملة. ويستبعد محرك اللوحة الجمعة والسبت والإجازات المحددة من الحسابات.

## ملاحظات

- الناتج ملف محلي **يحمل أسماء الطلاب وبيانات غيابهم داخل HTML**: **لا تنشره على GitHub أو أي موقع عام**.
- الواجهة الحالية لا تستورد ملف Excel مباشرة عند فتح الصفحة؛ يتولى سكربت Python إنشاء نسخة HTML جديدة من الملف. يمكن تطوير واجهة استيراد داخل المتصفح لاحقًا لنسخة الاستضافة.
- إعدادات الإجازات المحفوظة في المتصفح لا تنتقل تلقائيًا مع الملف؛ يمكن استخدام تصدير/استيراد إعدادات الإجازات عند الحاجة.
- إذا تضمن المصدر سجلات نصف يوم (`0.5`) فالمحرك الحالي يعدّها سجلات غياب فردية، ولا يحولها إلى مجموع أيام كسري؛ يظهر تحذير بذلك أثناء التوليد.
- السكربت مُختبر بمقارنة ملف Excel الأصلي مع نسخة اللوحة الأخيرة؛ تطابق عدد الطلاب (651)، وسجلات الغياب (12092)، والتواريخ (64)، وكل أزواج الطالب/التاريخ.

## الأمان والنشر

- هذا المستودع يحتوي على **الكود والقالب الخالي من بيانات الطلاب فقط**. لا تُرفع ملفات Excel أو PDF أو HTML المولّدة من بيانات فعلية.
- جميع ملفات HTML الناتجة من السكربت تحتوي على أسماء الطلاب وأرقامهم وسجلات غيابهم، لذلك تحفظ محليًا فقط.
- خاصية الاستيراد المباشر من المتصفح غير متوفرة بعد. موقع GitHub Pages ليس خاصًا تلقائيًا حتى لو كان المستودع خاصًا.
- ملف `.gitignore` يستبعد ملفات البيانات والتقارير وملفات HTML الناتجة كإجراء وقائي، لكنه لا يغني عن فحص الملفات قبل النشر.


## الاستيراد المباشر من المتصفح — GitHub Pages

يمكن استخدام `index.html` لاختيار ملف `.xlsx` بنفس بنية كشف الغياب الأصلي (C تاريخ، G فصل، L اسم الطالب، O رقمه)، ثم تحليل البيانات محليًا دون رفع الملف إلى أي خادم.

- الرابط المتوقع بعد تفعيل GitHub Pages: https://alharbikh.github.io/student-report/
- النشر عبر GitHub Actions في `.github/workflows/deploy-pages.yml`، ويشمل `index.html` و`قالب_مرصد_غياب_الطلاب.html` فقط.
- توجد خطوة أمان تمنع النشر إذا احتوى القالب على بيانات طلاب غير فارغة.
- جميع إحصائيات الغياب والفلاتر والإجازات والطباعة الموحدة تعمل بعد الاستيراد.
- استخدم Chrome/Edge حديثًا يدعم `DecompressionStream('deflate-raw')`.
- البيانات لا تُحفظ على الخادم؛ يلزم إعادة اختيار ملف Excel عند تحديث الصفحة. إعدادات الإجازات فقط تُحفظ محليًا.

### تفعيل GitHub Pages للمستودع الخاص

1. انتقل إلى [Settings → Pages](https://github.com/alharbikh/student-report/settings/pages).
2. اختر مصدر النشر **GitHub Actions** من **Build and deployment**.
3. افتح تبويب **Actions**، ثم شغّل سير العمل **Publish Student Absence Dashboard (no student data)** إذا لم يُنفّذ تلقائيًا.
4. افتح رابط **Visit site** بعد نجاح النشر.

> **الخصوصية:** موقع GitHub Pages عام افتراضيًا حتى عندما يكون المستودع خاصًا. لا ترفع ملفات Excel أو تقارير تحتوي على أسماء الطلاب إلى المستودع. النشر من مستودع خاص يحتاج إلى خطة GitHub مؤهلة مثل GitHub Pro.
