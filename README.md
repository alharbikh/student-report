# مرصد غياب الطلاب — GitHub Pages

لوحة تفاعلية لتحليل كشف غياب الطلاب، مع **معاينة بيانات المصدر وبطاقة جودة البيانات قبل بدء التحليل**، دون إرسال سجلات الطلاب إلى GitHub أو الخادم.

**رابط الموقع:** https://alharbikh.github.io/student-report/

## الاستخدام المباشر

1. افتح الموقع واختر كشف الغياب بصيغة `.xlsx` أو نسخة مرصد سابقة بصيغة `.json`.
2. تظهر **مرحلة المعاينة** أولًا، وفيها بطاقة جودة البيانات وجدول موحد للسجلات مع البحث، واختيار الصف الدراسي، وتصفية أيام الدوام وأيام العطلة والأيام ذات الغياب المرتفع.
3. راجع الملاحظات، ويمكنك حفظ نسخة من بيانات الملف بصيغة **JSON** لاستيرادها مرة أخرى لاحقًا.
4. اضغط **«اعتماد البيانات وبدء التحليل»** للانتقال إلى لوحة الإحصائيات. لن تبدأ التحليلات قبل الاعتماد.
5. استخدم المرشحات والتقويم والإجازات (الجمعة والسبت مستبعدان افتراضيًا)، ثم اطبع القسم الحالي أو تقريرًا شاملًا واحدًا.

> تحذير: **ملف JSON الناتج يحتوي على أسماء الطلاب وأرقامهم وسجلات الغياب**. يُحفظ على جهاز المستخدم فقط؛ لا ترفعه إلى المستودع العام ولا تشاركه مع غير المخولين. هذا التصدير لا يحذف أو يغيّر بيانات المصدر.

## أعمدة Excel المدعومة

| العمود | المحتوى |
|---|---|
| C | تاريخ الغياب |
| G | الفصل مثل «أول 1» أو «ثاني 2» أو «ثالث 3» |
| L | اسم الطالب |
| O | الرقم التعريفي للطالب |
| H2 | اسم المدرسة (اختياري) |

تبدأ سجلات الكشف المعتاد من الصف 12. يُفصل **صف إجمالي الغياب** عن سجلات الأيام، مع اكتشاف السجلات المكررة والناقصة والتواريخ غير الصالحة وأيام العطل والأيام شديدة الغياب. هذه ملاحظات تدقيق إحصائي، وليست قرارات إدارية آلية.

## كيف تعمل الخصوصية؟

- يحتوي موقع GitHub Pages على `index.html` وقالب التحليل الخالي من بيانات الطلاب فقط.
- تتم قراءة Excel وJSON في ذاكرة المتصفح محليًا. لا ترفع أسماؤهم أو سجلاتهم إلى أي خادم.
- لا تدخل البيانات إلى التحليلات إلا بعد الضغط على زر اعتماد المعاينة.
- يختفي ملف التحليل المحمّل من الجلسة عند إعادة تحميل الموقع، بينما تُحفظ إعدادات الإجازات فقط في تخزين المتصفح المحلي.
- تصدير JSON ينشئ نسخة **حساسة** محليًا، ويتيح إعادة استيرادها في جلسة أخرى.
- تُستخدم خطوط Cairo لواجهة العرض، والقالب الطباعي الافتراضي يستخدم Tajawal.

## ملفات المشروع

- `index.html`: استيراد XLSX/JSON، مراجعة جودة البيانات، عرض الجدول، واعتماد التحليل.
- `قالب_مرصد_غياب_الطلاب.html`: محرك الإحصائيات والتصفية والمقارنات والتقويم والطباعة.
- `إنشاء_مرصد_الغياب.py`: سكربت مستقل لمن يفضل إنتاج ملف HTML محلي من Excel باستخدام Python.
- `tests/validate-generated-dashboard.mjs`: فحص سلامة JavaScript في الملف المولد.
- `.github/workflows/deploy-pages.yml`: نشر الملفات الآمنة فقط بعد اجتياز اختبارات الخصوصية والكود.

## إنشاء لوحة محلية باستخدام Python (اختياري)

```powershell
python .\إنشاء_مرصد_الغياب.py ".\غياب_جديد.xlsx"
```

ويمكن تحديد الفترة الافتراضية:

```powershell
python .\إنشاء_مرصد_الغياب.py ".\غياب_جديد.xlsx" --start 2026-09-27 --end 2026-11-09
```

الملف الناتج محلي ويحتوي على بيانات الطلاب. لا ترفعه إلى GitHub Pages.

## النشر

المستودع **عام** وتُنشر الصفحة باستخدام **GitHub Actions** في `Settings → Pages` دون إنشاء قوالب Jekyll إضافية. عند تعديل الواجهة أو القالب، يعمل سير النشر تلقائيًا؛ ويُمنع النشر إذا احتوى القالب على سجلات طلاب أو تعذر تحليل JavaScript للوحة الناتجة.
